# GiftGenius — Netlify Ready

Static, responsive implementation of the supplied GiftGenius screenshots.

## Deploy
Upload the folder or ZIP to Netlify. No build command or API key is required.

## Included
- Landing page matching the supplied design
- 5-step interactive gift quiz
- Multi-select interests
- Personality and budget selection
- AI-style local recommendation scoring
- Recommendation cards
- Save/unsave using localStorage
- Share results
- Responsive mobile layout

The demo uses local JavaScript for the recommendation engine. For production, replace the scoring function with a backend/LLM API.
